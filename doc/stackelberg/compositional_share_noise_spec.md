# Prespecified compositional-share-noise stress design

Status: implementation specification, 2026-09-15.

This experiment is a sampler-geometry stress test.  It does not replace,
relabel, or rescue the primary exact-share recovery experiment.  The primary
gate failures remain failures.  The stress design changes only the synthetic
share-measurement process and records that change in its run manifest.

## Construction

Let `q0[j,t]` be the conditional inside quantity share generated by the
existing Logit or CES demand oracle.  Let `s0.base` be its Bayes-normalized
outside quantity share.  Independently draw

    e[j,t] ~ Student-t(df = 5, scale = sigma.share * sqrt(3 / 5)).

For each market-period define

    Z[t] = sum_j q0[j,t] * exp(e[j,t]),
    q[j,t] = q0[j,t] * exp(e[j,t]) / Z[t],
    logit(s0[t]) = logit(s0.base) - log(Z[t]).

Then `q[,t]` is a valid composition and the fitted conditional-share equation
has exactly the intended residual:

    log(q[j,t]) - log(q.pred[j,t] | s0[t]) = e[j,t].

The construction therefore avoids the zero-residual scale geometry without
pretending that independent unnormalized product shares can sum to one.  The
true outside share is period-specific and must be recorded and assessed
period-by-period.

Observed firm shares, observed CES revenue shares, and the fixed whole-market
firm ranking are computed from `q`, not `q0`.  The top-two truth is assigned
from that predetermined observed ranking.  Conditional margin means are then
computed from the same observed firm shares and period-specific outside share
used by the estimator.  This matches the implemented conditional joint model;
it does not substitute latent mean shares into the supply likelihood.

The default `sigma.share = 0` preserves the existing exact-share DGP bit for
bit, including its random-number stream.  The first stress value is fixed in
advance at `sigma.share = 0.04`, equal to the already specified margin-noise
standard deviation.  No value may be selected because it produces a preferred
posterior over k.  A later `0.02` sensitivity is permitted only if both values
are reported.

## Runner and provenance contract

The recovery runner gains an explicit `--share-noise-sd` option.  Its default
is zero.  A nonzero value must appear in the output-directory manifest and in
every diagnostic row.  Primary and stress outputs use different directories;
the runner must never merge them or overwrite one with the other.

Outside-share recovery reports at least the mean error and RMSE across matched
market-period posterior means.  Pooling all outside-share draws and comparing
them with only the average truth is not sufficient for the stress experiment.

The existing gates remain unchanged: maximum R-hat at most 1.01, minimum ESS
at least 100, minimum BFMI at least .30, zero divergences, and zero maximum-
treedepth hits.  The first execution is a one-case Logit-Bertrand Stackelberg
geometry diagnostic.  Expansion to every demand/conduct/layout combination is
allowed only after that case passes or yields a documented new diagnosis.

## Required validation

Tests must establish:

1. zero noise exactly reproduces the existing DGP and oracle tables;
2. noisy conditional shares are positive and sum to one in every period;
3. the share residual equals the stored Student-t draw to numerical tolerance;
4. period-specific outside quantity and CES revenue shares use the documented
   normalization;
5. rankings and roles are fixed before estimation and use observed shares;
6. margin predictions at truth equal the generated conditional means;
7. the run manifest and diagnostics distinguish primary from stress results;
8. no fit object, sampler log, or generated artifact is written to Git.

## Interpretation

A passing stress run establishes that nonzero share measurement error removes
the exact-fit sampler pathology for that design.  It does not establish that
the primary exact-share run passed, that every k is strongly identified, or
that the PNB application will mix.  Ordered-k identification continues to be
judged separately using truth-state likelihood scores and multi-seed recovery.
